# Paid to Bring Peace: Issue 02 — Full Sales Page Concept

A responsive, static HTML/CSS/JavaScript demo for a premium physical-publication sales page.

## Preview

Open `index.html` in a modern browser. No build step, server, or third-party dependencies are needed.

## What's included

- Responsive hero with editorial artwork, navigation, and jump links
- Six individual issue features and curiosity-led summaries
- Physical-publication showcase with working three-image gallery
- Editor section with imagery from the existing page screenshots
- Private-audio community excerpts (clearly labeled)
- One-time $100 offer layout with interactive **demo-only** checkout dialog
- Expandable FAQ, sticky navigation, smooth anchors, mobile menu, scroll progress and subtle reveal effects

## Where to edit

- **Headline and copy:** `index.html`. Each section is marked with a numbered HTML comment.
- **Colors/layout:** `styles.css` CSS variables at the top.
- **Gallery interactions:** `script.js` `slides` array.
- **Images:** `assets/` (all images are WebP).
- **Price/terms:** `index.html` #order. `$100` is a draft price based on the current page, not a live offer.

## Before publishing

1. Replace the conceptual Issue 02 product art with approved/actual imagery; Issue 01 photography is labeled.
2. Confirm manuscript topics and exact promised deliverables (all six sections are provisional).
3. Confirm print and shipping dates, worldwide shipping terms, and any digital or community bonuses.
4. Confirm purchase policies and connect an appropriate external checkout flow.
5. Validate every statement and verify community quote permissions; do not present audio feedback as issue reviews.
6. Test live checkout and post-purchase confirmation on mobile and desktop.

No payments are collected by this prototype.
